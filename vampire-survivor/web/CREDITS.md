# Crédits des assets

Tous les assets utilisés ici proviennent du dépôt GitHub **`libertysand1982-png/Sand`**,
dossier `rpg_game/godot_export/assets/`. Ce sont des packs d'assets **Kenney**
(<https://kenney.nl>), distribués sous licence **CC0 1.0** (domaine public).

## Images — personnages (`assets/characters/`)
| Fichier        | Rôle dans le jeu      |
|----------------|-----------------------|
| `hero.png`     | Joueur                |
| `gobelin.png`  | Ennemi de base        |
| `bandit.png`   | Ennemi intermédiaire  |
| `garde.png`    | Ennemi lourd (barre de vie) |

## Images — interface (`assets/ui/`)
Barres horizontales Kenney en 3 tranches (`barBack_*`, `barRed_*`) utilisées
pour la barre de vie du joueur et celle des ennemis lourds.

## Audio (`assets/audio/`)
| Fichier            | Usage                    |
|--------------------|--------------------------|
| `knifeSlice.ogg`   | tir de l'arme            |
| `knifeSlice2.ogg`  | variante de tir          |
| `metalClick.ogg`   | projectile qui touche    |
| `handleCoins.ogg`  | ramassage d'une gemme    |
| `footstep00.ogg`   | pas du héros             |
| `drawKnife1.ogg`   | héros blessé             |
| `click1.ogg`       | clics de menu            |

## Code
Code du jeu écrit pour ce projet (HTML5 Canvas + JS vanilla). Réutilisable librement.
